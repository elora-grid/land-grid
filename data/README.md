# Data release candidate — 11 November 2026

`catalogue.ndjson` is a six-record public reader example derived from the already reviewed Irish NPAD sample release. The compatible application import packet is under `releases/ireland/`; its manifest retains exact checksums. It adds readable project titles and original screening explanations to the reviewed source sample, while retaining record IDs, geometry, dates, stage and evidence; metadata records the source sample reference. Neither inclusion here nor an HTML preview activates a production release.

Attribution: **Department of Housing, Local Government and Heritage — National Planning Applications Database**, [source API](https://services.arcgis.com/NzlPQPKn5QF9v2US/arcgis/rest/services/IrishPlanningApplications/FeatureServer?f=pjson), [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Original source dates, references and limitations are retained in the packet. Elora added the research identity, status interpretation and 1,500 m screening uncertainty; points are not surveyed building footprints.

The source reports planning approvals, not current computing operation, current ownership or open procurement. Probability, builder and electrical-contractor fields remain unknown. Source-signal certainty scores in the compatible import packet are not probabilities.

Internal European archives, acquisition logs, private assessments, personal saves and contacts are excluded. Further releases require documented source redistribution rights and source-backed identity/status/location review.
